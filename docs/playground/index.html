Install ReflexRun

Requires Node.js 20+, npm and Codex Desktop with Computer Use.

1. Check your tools.

git --version
node --version
npm --version

2. Clone ReflexRun.

git clone https://github.com/kehuitt/ReflexRun.git
cd ReflexRun

For a source ZIP, run these commands in the folder containing it. 

unzip reflexrun.zip
cd reflexrun

3. Install and verify.

npm run setup:codex && node dist/src/cli.js doctor

Once you see “ready: true”, open a new chat and describe the task. Hosts that match skills automatically can load ReflexRun from your request. To select it explicitly in a host that supports $ mentions, try “$reflexrun archive these three emails.”

Optional instructions for AGENTS.md

If your host reads AGENTS.md, you can add this rule yourself. The installer leaves AGENTS.md untouched. 

For Computer Use tasks, load the reflexrun skill if available and look for matching experience before acting. Reuse it when applicable and follow the host’s permission and verification rules.

4. To try the sample, start the local demo and leave its terminal running. 

npm run demo

Open the practice inbox ↗ Ask this in a new chat in the project with Computer Use available. 

Move MAIL-5101 to Archive in the practice inbox.

After the first task finishes, open a new chat and ask for the next batch. 

Move MAIL-5102 and MAIL-5103 to Archive.

The Skill saves verified workflows to ~/.reflexrun/memory/ by default. Matching workflows are available across projects and chats under the same local user account.

To update an earlier install, run these commands in the ReflexRun source directory. For a store in another project, use its absolute path. 

npm run setup:codex -- --upgrade
node dist/src/cli.js memories import --memory .reflexrun/memory
